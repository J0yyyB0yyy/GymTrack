# GymTrack V3.2

Personal React + TypeScript + Vite gym tracker.

## V3.2 — Workout Experience

- Improved active workout header with elapsed time and set completion progress.
- Previous workout values shown directly on each exercise.
- Integrated rest timer with presets, auto-start, pause/resume, +30 seconds and skip.
- Quick set entry for logging a completed set immediately.
- Workout notes saved with the workout.
- Templates retain exercise order and set counts, show a compact summary, and can be duplicated.
- Existing V3.0 features retained: custom exercises, favorites, recent exercises, swipe navigation, simplified navigation, and dashboard weekly summary.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
